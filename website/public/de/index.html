Schluss mit Suchen im Keller.

ChaosGone ist eine kostenlose Open-Source-App fürs Kellerinventar. Dinge fotografieren, von KI beschreiben lassen und in Sekunden wiederfinden.

Auf GitHub ansehen So funktioniert's

Das Problem

Du hast es. Du findest es nur nicht.

Der 8-mm-Bohrer, der Fahrradschlauch, die Ersatzbirnen: irgendwo im Keller. Nach einer Stunde Kistenwühlen kaufst du es neu. Schon wieder.

  • Doppelt gekauftDinge, die du längst besitzt, aber nicht gefunden hast.
  • Eine Stunde wegKisten durchwühlen für etwas, das eine Minute dauert.
  • Kein ÜberblickNiemand weiß, was in welcher Kiste liegt. Du auch nicht.

So funktioniert's

Drei Schritte. Keine Tabelle.

  1. 1

    Fotografieren

    Jedes Teil mit dem Handy knipsen, oder eine ganze Dose Dübel als Sammlung. Hunderte Fotos? Alle in einem Rutsch importieren.

  2. 2

    KI beschreibt

    Claude schreibt Namen, Beschreibung und Inhaltsliste. Du prüfst und korrigierst, wann du magst.

  3. 3

    In Sekunden finden

    Ein Suchfeld. Tippfehler, Mehrzahl und halbe Wörter sind kein Problem, auf Deutsch und Englisch.

Funktionen

Gebaut für einen echten Keller

  • Kisten-Kacheln

    Eine Handvoll großer Kacheln für den Daumen: Fahrrad, Werkzeug, Sport.

  • Clevere Suche

    Fehlertolerant und deutschsprachig. Kostenlos und lokal; Claude nur, wenn du willst.

  • Sammlungen

    Sortimente werden zu Listen: Dübel, Schrauben und Scheiben nach Sorte.

  • Stapel-Import

    Hunderte Fotos auf einmal. Die Ergebnisse prüfst du in deinem Tempo.

  • Barcode-Scan

    EAN-Codes mit der Handykamera scannen.

  • Deine Daten

    Eine SQLite-Datei und ein Fotoordner bei dir zu Hause. Kein Konto, kein Lock-in.

Kostenlos & Open Source

Läuft auf dem Raspberry Pi. Kostet nichts.

  • MIT-Lizenz: nutzen, ändern, weitergeben.
  • Kein Konto, kein Abo, kein Tracking.
  • Läuft auf dem Raspberry Pi, jedem Linux-Rechner oder in Docker.
  • Deine Daten sind eine SQLite-Datei plus ein Fotoordner: ein einfaches Kopieren genügt als Backup.
  • Die optionalen KI-Funktionen nutzen deinen eigenen Claude-API-Schlüssel. Du zahlst nur, was du verbrauchst.

Auf dem Pi installieren

$ git clone https://github.com/jzakotnik/chaosgone.git
$ cd chaosgone && npm install
$ cp .env.example .env.local  # API-Schlüssel eintragen
$ npm run build && pm2 start ecosystem.config.cjs
# danach http://raspihome:3500 öffnen

FAQ

Gut zu wissen

Ist das wirklich kostenlos?

Ja. ChaosGone ist Open Source unter der MIT-Lizenz: kein Konto, kein Abo, keine Werbung. Kosten entstehen nur optional: Die Fotoerkennung nutzt die Claude-API mit deinem eigenen Schlüssel, und du zahlst Anthropic nur für die Nutzung.

Was brauche ich zum Betrieb?

Einen Raspberry Pi mit 64-Bit-System, einen beliebigen Linux-Rechner oder Docker. Die Einrichtung sind ein paar Befehle mit pm2 oder Docker; das README führt dich durch.

Verlassen meine Fotos mein Netz?

Die Fotos liegen auf deinem eigenen Rechner. Nur wenn du eine Claude-Funktion nutzt (Erkennen, Stapel-Import, Neu erzeugen), wird das verkleinerte Foto an die API von Anthropic geschickt. Die normale Suche ruft die API nie auf; die optionale KI-Suche schickt das Inventar als Text, ohne Fotos.

Geht es auch ohne KI?

Ja. Du kannst Teile von Hand erfassen und durchsuchen. Nur Fotoerkennung und KI-Suche brauchen einen API-Schlüssel.

Welche Sprachen gibt es?

Die Oberfläche gibt es auf Deutsch und Englisch, und Claude schreibt die Beschreibungen in der gewählten Sprache.
